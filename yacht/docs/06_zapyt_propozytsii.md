# ВК-90. Запит попередньої пропозиції на побудову, проєкт листа

Статус: чернетка для Віктора. Не надіслано. Поля у квадратних дужках заповнює замовник.

Тема: Запит щодо побудови вітрильної яхти 9,0 м за проєктом замовника

Добрий день!

Шукаю виконавця для побудови однієї вітрильної крейсерської яхти за власним проєктом. Прошу повідомити, чи цікаве вам таке замовлення і на яких умовах.

Об'єкт:

| Параметр | Значення |
|---|---|
| Тип | кілевий вітрильний крейсер, дробовий шлюп, 4 спальні місця |
| Довжина корпусу | 9,00 м |
| Найбільша ширина | 3,11 м |
| Осадка | 1,60 м, фіксований плавниковий кіль зі свинцевим бульбом |
| Водотоннажність порожнем | близько 3,85 т, з них баласт 1,45 т |
| Корпус | морська фанера, гострі вилиці, по три пояси на борт, шиття і склеювання на епоксидній смолі, обклеювання склотканиною |
| Площа обшивки корпусу | близько 37 м2 без палуби й рубки |
| Двигун | стаціонарний дизель 10-15 кВт із приводом |
| Щогла | алюмінієва, близько 12 м від даху рубки, покупна |
| Ціль за категорією проєктування | B |

Стан проєкту: виконано ескізний проєкт (обводи, гідростатика, остійність, загальне розташування, вітрильне озброєння). Робоча документація з файлами розкрою для верстата планується на березень 2027 року. Проєкт пройде незалежну перевірку корабельним інженером до початку будівництва.

Прошу відповісти на такі питання:

1. Чи маєте досвід побудови корпусів із фанери на епоксидній смолі, яких розмірів і коли?
2. Який розмір робочого поля вашого фрезерного верстата і з яким форматом аркуша фанери працюєте?
3. Чи є опалюваний цех із воротами й висотою, достатніми для корпусу 9,0 x 3,1 м заввишки близько 3,3 м разом із кілем?
4. Який обсяг робіт готові взяти: лише корпус із палубою, корпус з оснащенням чи яхту під ключ?
5. Орієнтовна вартість робіт і строк для кожного з трьох обсягів, окремо від матеріалів.
6. Чи виливаєте свинцевий бульб самі, чи замовляєте на стороні?
7. Чи маєте досвід оцінки відповідності за Технічним регламентом прогулянкових суден і чи видаєте декларацію про відповідність як виробник?
8. Найближче місце спуску на воду і чи організовуєте перевезення негабаритного вантажу завширшки 3,11 м.

Ескізні креслення надішлю на запит.
